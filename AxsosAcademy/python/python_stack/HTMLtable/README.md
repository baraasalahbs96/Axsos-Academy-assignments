# HTML Table Flask Project

## 📌 Description
This project demonstrates how to pass data from a Flask route to an HTML template and display it as a styled table using Bootstrap.

The data is a list of dictionaries representing users.

---

## 🧠 What I learned
- Creating Flask routes
- Passing data from Python to HTML templates
- Using Jinja2 templating engine
- Looping through a list of dictionaries
- Using Bootstrap to style a table

---

## ▶️ How to Run the Project

### 1️⃣ Install Flask
Open terminal and run:

pip install flask

### 2️⃣ Run the server

python app.py

### 3️⃣ Open browser and go to:

http://127.0.0.1:5000/
